# 📚 Sistema de Avaliação de Alunos

Este projeto em Java permite o cadastro de alunos e suas respectivas notas, valida as entradas e determina automaticamente quem foi aprovado ou reprovado com base em uma média definida pelo usuário.

---

## 🚀 Funcionalidades

✅ Entrada da média de aprovação definida pelo usuário  
✅ Cadastro de múltiplos alunos e suas notas  
✅ Validação do nome (sem números)  
✅ Validação da nota (somente valores numéricos)  
✅ Exibição dos resultados com total de aprovados e reprovados  

---

## 🧠 Regras de Validação

🔒 **Nome do aluno**:  
- Não pode conter números.  
- Entrada inválida força o usuário a tentar novamente.

🔢 **Nota do aluno**:  
- Deve ser um número válido (ex: `7.5`, `10`, etc).  
- Letras ou símbolos inválidos não são aceitos.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Scanner (entrada de dados via terminal)
- Console (modo texto)
